# Evaluación Final - Programación de Componentes

Proyecto integrador en React con Firebase y empaquetado móvil con Cordova.

- **Netlify:** https://rodrigo-vergara-programacion-compon.netlify.app/
- **GitHub:** https://github.com/UnTalPeluca/evaluacion-final-programacion-componentes

## Ejercicios

- **Ejercicio 1:** Catálogo de productos con carrito de compras (`map`, `props`, `state`).
- **Ejercicio 2:** Formulario con validación (`simple-react-validator`) conectado a Firestore Database.
- **Ejercicio 3:** Estilos con Bootstrap, Firebase Auth/Storage y APK compilado con Cordova (`app-examen-final.apk`).

# Con Bun
